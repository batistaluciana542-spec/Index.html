# NEON RIFT // Arena

Jogo multiplayer 2D para navegador, criado para rodar no GitHub Pages.

## Recursos
- Multiplayer P2P por PeerJS
- Salas com código
- Nome personalizado
- 8 cores de piloto
- Até 8 jogadores
- Movimento por teclado e joystick no celular
- Mira pelo mouse/toque
- Tiro e dash
- HP, eliminações, pontos, moedas e nível
- Ranking da partida
- Chat em tempo real
- Drops de moedas e cura
- Respawn
- Visual neon responsivo

## Como jogar
1. Publique o repositório com GitHub Pages.
2. Abra o jogo.
3. Escolha seu nome.
4. Para criar uma partida, use CRIAR SALA e compartilhe o código.
5. Os outros jogadores usam o mesmo código em ENTRAR NA SALA.

## GitHub Pages
Em Settings > Pages, escolha Deploy from a branch, selecione main e a pasta / (root).

O multiplayer usa o serviço de sinalização do PeerJS. O GitHub Pages hospeda os arquivos do jogo; a comunicação da partida acontece diretamente entre os navegadores quando a conexão P2P é estabelecida.
